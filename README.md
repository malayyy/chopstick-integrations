# Chopstick Integrations

A React, TypeScript, and Vite project for a scroll-driven cinematic reveal, using
300 numbered image frames.

## Run locally

```bash
cd files
npm install
npm run dev
```

Open the local URL printed by Vite. The app serves its frames from the sibling
`frames/` directory. To build for production, run `npm run build` from `files/`.

See [files/README.md](./files/README.md) for project details and frame notes.
